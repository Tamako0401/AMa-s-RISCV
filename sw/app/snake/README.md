# snake: 贪吃蛇

`ama run snake` (上板) 或 `ama sim snake` (仿真, 在窗口里打字操作)。

## 玩法

上电黑屏, 等开局: 按开局键或任一方向键 (串口: 空格、`p` 或 `wasd`/`hjkl`)。绿色是蛇, 红色是食物。
游戏中开局键 (或串口空格、`p`) 是暂停。撞死停 1 秒, 再等下一局。

| 操作 | 盘古 MES50HP | EGO1 | 串口 |
| --- | --- | --- | --- |
| 上 / 下 / 左 / 右 | KEY7 / KEY6 / KEY5 / KEY8 | S4 / S1 / S3 / S0 | `w` `s` `a` `d` 或 `k` `j` `h` `l` |
| 开局 / 暂停 | KEY2 | S2 (中间) | 空格、`p` |
| 穿墙 开/关 | KEY4 每按一下切换, LED4 显示 | 拨码 SW0, LD2_0 显示 | |
| 串口控制 开/关 | KEY3 每按一下切换, LED3 显示 | 拨码 SW1, LD2_1 显示 | |

穿墙打开时, 从一边出去从对边回来; 关闭时撞墙算死。屏幕大小运行时读取: 240×320 屏每格 10 像素, 128×160 屏每格 8 像素。

## 文件

| 文件 | 内容 |
| --- | --- |
| `snake.c` / `snake.h` | 游戏逻辑, 不碰硬件 (格子、移动、吃食物、撞死), 电脑上也能编译 |
| `main.c` | 读按键和串口、按节拍走一步、只重画变化的格子 |
| `boards/<板>/app_board.{h,c}` | 本板哪个键是上下左右, 两个开关怎么读 (盘古用按键切换, EGO1 用拨码) |
| `test/host_test.c` | 在电脑上测 `snake.c` 的逻辑: `ama test sw/app/snake/test` |

## 测试

- `ama test sw/app/snake/test`: 电脑上跑游戏逻辑。
- `tests/soc/snake_tb.sv`: 仿真里经串口发 `d`、`s`, 核对蛇在屏幕上的位置。
- 仿真时一步的间隔固定为 100 万拍 (`SNAKE_STEP_CYCLES`), 要够串口收一个字符; 上板是 150 毫秒。
