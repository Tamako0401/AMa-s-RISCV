# 赛题要求与答疑要点

2026 全国大学生嵌入式芯片与系统设计竞赛, FPGA 创新设计赛道, 紫光同创选题一「基于紫光同创 RISCV 指令集 CPU 设计」。
原件 (不进仓库): 选题指南 PDF 和官方答疑表在 `~/fpga/competition/` (队友各自从赛事群获取)。下文 [Qn] 是答疑表的问题序号。

## 任务

| 类 | 要求 |
| --- | --- |
| 基础 | 支持 RV32I 的处理器; 不少于 3 级流水线, 处理数据冲突和分支跳转; 集成 UART、GPIO 等基础外设 |
| 高阶 1 | 2 路组相联的指令和数据 Cache, 优化总线突发传输 |
| 高阶 2 | 动态分支预测 (如 BTB); 完整的 RISC-V 异常/中断处理 |
| 高阶 3 | 边缘 AI 加速单元 (YOLO 或轻量大模型), 融合传感器或显示, 做图形加速、语义识别或机械控制。AI 只是推荐方向 [Q84] |
| 环境 | 紫光同创 FPGA 板 (盘古 50K 够用 [Q20]); 工具链 riscv32-unknown-elf-gcc; CoreMark v1.0 (官方不提供源码 [Q48]) |

## 评分

- 性能: CoreMark/MHz、满足约束的最高频率、CoreMark/LUT。
- 应用场景 (例: 游戏机、图像加速卡): 模型的资源、时序、主频; AI 处理效率看延迟和识别率。
- 技术实现与文档: 代码规范 (模块化、时序约束合理、注释完整); 性能分析报告, 要用 **ILA 抓的波形**分析 CPU 跑 CoreMark 关键算法时的流水线效率。
- 没有公布各项权重。

## 答疑里定下的规则

- **先看应用, 再看性能** [Q4][Q11][Q52]: 按"特定场景下整个作品的能力"评; 资源和跑分都是同等功能下比较 [Q46][Q63]。不接受只为跑分优化、没有实际功能的作品 [Q11]。两者都要, 不能只停在仿真 [Q93]。
- 报告要有完整的资源使用说明、时序说明、CPU 结构框图 [Q4]。
- **时序违例不被接受** [Q7]。
- **跑分和应用在同一个位流** [Q53]; 跑分时可以关外设 [Q25]。
- 允许硬件加速 [Q9]、扩展指令集 [Q79]; AI 加速单元可以不走 AXI、可以用 RVV [Q12]; **不能用 ARM 硬核** [Q44]。
- 指令/数据存储没有限制 (可以全用片上 RAM) [Q6]。外设自选 [Q61]。模型可以放 SD 卡 [Q60]。
- 初赛提交: 设计文档、代码、演示 PPT、演示视频一整套最好, 初评在线 [Q71]。初赛不借板卡 [指南]。
- CoreMark 必须设迭代次数, 运行不少于 10 秒 [指南]。

## 还没问清的

- CoreMark/LUT 的 LUT 是 CPU 还是整个设计 (提问过, 没有正式答复)。
- 只做图形加速、不做 AI 时高阶 3 怎么算; 选题一的提交截止时间和格式。
- 基于开源核修改的 CPU 怎样认定自主设计 (本仓库 CPU 来源见 [cpu-baseline.md](cpu-baseline.md)、[third-party.md](third-party.md))。
